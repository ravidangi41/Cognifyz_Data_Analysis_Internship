# Cognifyz Data Analysis Internship

This repository contains my Data Analysis projects completed during the Cognifyz Technologies Internship.

The project focuses on analyzing a restaurant dataset using Python, Pandas, Matplotlib, and data analysis techniques.

## 📊 Project Overview

The analysis covers restaurant data and extracts meaningful insights related to cuisines, pricing, ratings, online delivery, geographic distribution, and restaurant chains.

## 🟢 Level 1 Tasks

### Task 1 – Top Cuisines
- Identified the most common cuisines in the dataset.
- Analyzed the distribution of restaurants across different cuisines.

### Task 2 – City Analysis
- Analyzed restaurant distribution across cities.
- Identified cities with the highest number of restaurants.

### Task 3 – Price Range Analysis
- Analyzed the distribution of restaurants across different price ranges.
- Identified the most common price range.

### Task 4 – Online Delivery
- Analyzed restaurants offering online delivery.
- Compared average ratings of restaurants with and without online delivery.

## 🔵 Level 2 Tasks

### Task 1 – Restaurant Ratings
- Analyzed the distribution of aggregate restaurant ratings.
- Identified the most common rating range.
- Calculated the average number of votes received by restaurants.

### Task 2 – Cuisine Combination
- Identified the most common combinations of cuisines.
- Analyzed whether certain cuisine combinations tend to have higher ratings.

### Task 3 – Geographic Analysis
- Plotted restaurant locations using longitude and latitude.
- Identified geographic patterns and clusters of restaurants.

### Task 4 – Restaurant Chains
- Identified restaurant chains present in the dataset.
- Analyzed their popularity based on the number of outlets.
- Compared ratings and performance of different restaurant chains.
